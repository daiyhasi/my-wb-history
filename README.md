# my-wb-history

WorkBuddy 本地任务数据的跨设备归档仓库。

WorkBuddy 的任务列表只保存在本机（`~/.workbuddy/workbuddy.db` + `projects/*.jsonl`），换电脑登录看不到。这个仓库用来把任务摘要与本地产出物同步到云端，作为可翻阅、可携带的历史记录。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 可视化看板，浏览器直接打开即可浏览全部任务 |
| `workbuddy-任务数据总览.md` | 完整总结报告（总览表 + 逐任务要点 + 结论与待办） |
| `data/workbuddy-tasks-2026-10-19.json` | 结构化快照（任务元数据、轮次、tokens、积分、提问索引、最后回复摘要） |

## 说明

- 本仓库是**摘要级**归档，不含对话原文。原文仍在 `~/.workbuddy/projects/<工作区>/<session-id>.jsonl`，需要完整还原时按 JSON 快照里的 `id` 字段对应取回。
- 任务 1、2 中的所有行情结论均为历史对话记录，数据时点为 2026-10-16 / 10-19，不代表当前行情，也不构成投资建议。
